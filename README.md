# 🌐 Cyber Lens — AI-Based Network Traffic Anomaly Detection  

> *When packets go rogue, Cyber Lens sees it first.*

---

## 🧠 Overview

**Cyber Lens** is an AI-powered system that automatically detects unusual network traffic patterns using **Machine Learning**.  
Instead of relying on traditional signature-based intrusion detection, Cyber Lens learns what *normal traffic* looks like — and flags anything suspicious.  

The project combines:
- 🧮 **Isolation Forest** & **Local Outlier Factor (LOF)** for unsupervised anomaly detection  
- 📊 Interactive **Streamlit Dashboard** for real-time visualization  
- ⚙️ Explainable insights for cybersecurity analysts  

---

## 🧩 Objectives
- Detect and classify anomalous network traffic automatically  
- Reduce false positives through dual-model cross-verification  
- Visualize anomalies and metrics in a user-friendly interface  
- Build an extendable framework aligned with **NIST Cybersecurity Framework** (Identify & Detect)
